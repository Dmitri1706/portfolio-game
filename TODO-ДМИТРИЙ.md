# Что нужно от Дмитрия

Список пополняется по ходу работы. Пока всё это заменено заглушками — игра работает и без них.
Как и куда всё вставлять — в README, раздел «Тексты, ссылки и материалы».

## Комната «В ХОД»

- [ ] Ссылка на ваш сайт → `content/settings.json` → `site.url` (сейчас стоит https://example.com)
- [ ] Длинный скриншот сайта (на случай, если сайт не встраивается) → `public/materials/site-screenshot.png`
- [ ] PDF презентации → `public/materials/presentation.pdf`
- [ ] PDF «МедиаКит» → `public/materials/mediakit.pdf`
- [ ] Ссылка на видео вебинара (VK Видео / Rutube / YouTube) → `settings.json` → `webinar.url`
- [ ] Резюме: текст → `content/resume.md`, PDF → `public/materials/resume.pdf`
- [ ] Тексты 4 кейсов (Задача → Что я сделал → Результат → Инструменты) → `content/cases/*.md`
- [ ] Фирменные цвета «В ХОД» (пришлите — подставлю, или см. README «Цвета акцентов»)
