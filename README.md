# Портфолио-игра Дмитрия Мельшина

Изометрическая пиксельная мини-игра-портфолио на **Phaser 3 + Vite + TypeScript**.

## Команды

Все команды выполняются в папке проекта (`C:\Projects\portfolio-game`).

| Команда | Что делает |
|---|---|
| `npm install` | Скачивает библиотеки (один раз, после скачивания проекта) |
| `npm run dev` | Запускает игру локально: откройте в браузере http://localhost:5173 |
| `npm run sprites` | Заново рисует все спрайты в `public/assets/sprites/` |
| `npm run build` | Собирает готовый сайт в папку `dist/` |

Остановить локальный сервер: в его окне терминала нажмите `Ctrl + C`.

## Спрайты: как заменить на свои

Все картинки описаны в одном манифесте — `src/assets/sprites.json`. Игра берёт PNG по имени файла из `public/assets/sprites/`.

**Заменить спрайт = положить свой PNG с тем же именем и тем же размером.**

Чтобы `npm run sprites` не перезаписал ваш файл, впишите его имя отдельной строкой в `public/assets/sprites/custom-sprites.txt` (создайте файл, если его нет).

Требования ко всем спрайтам: PNG с прозрачностью, без сглаживания (чёткие пиксели), изометрия 2:1, свет сверху слева.

| Файл | Размер | Что это |
|---|---|---|
| `floor_lobby.png` | 32×16 | Плитка пола лобби: ромб 2:1 |
| `floor_edge_left.png` / `floor_edge_right.png` | 16×22 | Толщина пола под крайними плитками |
| `wall_lobby_left.png` / `wall_lobby_right.png` | 16×80 | Кусок стены шириной в одну плитку, высота стены 72 px |
| `door_free_boarded.png` | 36×67 | Отдельно стоящая заколоченная дверь. Точка опоры (anchor) — пиксель (17, 56) |
| `shadow.png` | 16×6 | Тень под персонажем |
| `marker.png` | 64×8 | Маркер точки назначения: 4 кадра 16×8 в ряд |
| `player.png` | 96×160 | Персонаж: лист кадров 24×40, 4 столбца. Ноги стоят на строке 38 кадра |

### Лист персонажа `player.png`

Каждая строка — одна анимация, кадры идут слева направо. Персонаж нарисован смотрящим **вправо**, влево игра отражает его сама.

| Строка | Анимация | Кадров |
|---|---|---|
| 0 | стоит, лицом к нам (`idle_front`) | 2 |
| 1 | стоит, спиной (`idle_back`) | 2 |
| 2 | идёт, лицом к нам (`walk_front`) | 4 |
| 3 | идёт, спиной (`walk_back`) | 4 |

Новые анимации (сидит, держит предмет, спотыкается, падает) появятся на Этапе 2.

## Как устроен код

- `src/iso.ts` — перевод координат экран ↔ сетка.
- `src/world/IsoRoom.ts` — комната: пол, стены, проходимость клеток, поиск пути.
- `src/world/Player.ts` — персонаж: ходьба по пути, повороты в 4 направления, сортировка глубины.
- `src/scenes/` — сцены игры (загрузка, лобби, комнаты).
- `scripts/generate-sprites.mjs` — генератор спрайтов.
