# Портфолио-игра Дмитрия Мельшина

Изометрическая пиксельная мини-игра-портфолио на **Phaser 3 + Vite + TypeScript**.

## Команды

Все команды выполняются в папке проекта (`C:\Projects\portfolio-game`).

| Команда | Что делает |
|---|---|
| `npm install` | Скачивает библиотеки (один раз, после скачивания проекта) |
| `npm run dev` | Запускает игру локально: откройте в браузере http://localhost:5173 |
| `npm run sprites` | Заново рисует все спрайты в `public/assets/sprites/` |
| `npm run build` | Собирает готовый сайт в папку `dist/` |

Остановить локальный сервер: в его окне терминала нажмите `Ctrl + C`.

## Тексты, ссылки и материалы (без программирования)

Всё, что вы будете менять, лежит в папке `content/` и `public/materials/`. Код трогать не нужно. Пока запущен `npm run dev`, изменения появляются в браузере сами.

### Тексты кейсов — `content/cases/*.md`

| Файл | Где показывается |
|---|---|
| `content/cases/site.md` | Компьютер (сайт) в комнате «В ХОД» |
| `content/cases/presentation.md` | Сцена со зрителями |
| `content/cases/mediakit.md` | Газета-медиакит |
| `content/cases/webinar.md` | Телефон с вебинаром |
| `content/resume.md` | Папка-резюме. Страницы папки разделяются строкой `---` |

Это обычный текст в формате Markdown:
- `## Заголовок` — заголовок раздела (Задача, Что я сделал, Результат, Инструменты — лучше не удалять);
- строка, начинающаяся с `- ` — пункт списка;
- `**жирный**`, `_курсив_`;
- `[текст ссылки](https://адрес)` — ссылка;
- всё между `<!--` и `-->` — подсказка, на сайте не видна.

### Ссылки, пути к файлам и контакты — `content/settings.json`

```json
{
  "site": {
    "url": "https://адрес-сайта.ru",
    "embed": true,
    "screenshot": "materials/site-screenshot.png"
  },
  "presentation": { "pdf": "materials/presentation.pdf" },
  "mediakit": { "pdf": "materials/mediakit.pdf" },
  "webinar": { "url": "https://vkvideo.ru/video-123_456" },
  "resume": { "pdf": "materials/resume.pdf" },
  "contacts": { "telegram": "username", "email": "mail@example.com", "phone": "+7 900 000-00-00" }
}
```

- `site.url` — ваш сайт для компьютера. Если сайт не открывается внутри «монитора» (некоторые сайты запрещают встраивание), поставьте `"embed": false` — тогда сразу покажется длинный скриншот `site.screenshot`. Скриншот можно сделать, например, расширением GoFullPage в Chrome.
- `webinar.url` — обычная ссылка на видео из адресной строки: VK Видео, Rutube или YouTube. Пустые кавычки `""` — показывается заглушка.
- `contacts.telegram` — имя пользователя без `@`. Пустое поле `""` — контакт не показывается.
- Пути к файлам пишутся от папки `public/`: файл `public/materials/resume.pdf` → `"materials/resume.pdf"`.

**Как не сломать JSON:**
1. Текст — всегда в двойных прямых кавычках: `"так"`. Не «ёлочки» и не одинарные.
2. Между парами `"ключ": "значение"` ставится запятая, а **после последней пары в блоке — нет**.
3. `true` / `false` пишутся без кавычек.
4. Скобки `{ }` должны быть парными. Не удаляйте ключи слева от двоеточия — меняйте только значения справа.
5. Если после правки игра показала ошибку — проверьте файл на сайте jsonlint.com (вставьте текст и нажмите Validate).

### Материалы — `public/materials/`

Положите свои файлы с теми же именами (или поменяйте имена в `settings.json`):

| Файл | Что это |
|---|---|
| `presentation.pdf` | Слайды презентации на сцене |
| `mediakit.pdf` | МедиаКит в газете |
| `resume.pdf` | Резюме для кнопки «Скачать» |
| `site-screenshot.png` | Длинный скриншот сайта (запасной вариант) |

Сейчас там лежат пиксельные заглушки. Команда `npm run placeholders` создаёт заглушки только для **отсутствующих** файлов — ваши файлы она не трогает.

### Цвета акцентов «В ХОД»

Неоновые цвета комнаты задаются в `scripts/lib/palette.mjs` (строки `vhodNavy`, `vhodNeon`, `vhodNeon2`). Поменяйте цвета и выполните `npm run sprites` — все спрайты перерисуются.

## Спрайты: как заменить на свои

Все картинки описаны в одном манифесте — `src/assets/sprites.json`. Игра берёт PNG по имени файла из `public/assets/sprites/`.

**Заменить спрайт = положить свой PNG с тем же именем и тем же размером.**

Чтобы `npm run sprites` не перезаписал ваш файл, впишите его имя отдельной строкой в `public/assets/sprites/custom-sprites.txt` (создайте файл, если его нет).

Общие требования: PNG с прозрачностью, без сглаживания (чёткие пиксели), изометрия 2:1 (на 2 пикселя вбок — 1 вверх/вниз), свет сверху слева.

#### Лист персонажа `player.png`

Каждая строка — одна анимация, кадры идут слева направо, пустые клетки — прозрачные. Персонаж нарисован смотрящим **вправо**, влево игра отражает его сама. «Лицом» — смотрит на зрителя (вниз-вправо), «спиной» — от зрителя (вверх-вправо).

|---|---|---|
| 0 | стоит лицом (`idle_front`) | 2 |
| 1 | стоит спиной (`idle_back`) | 2 |
| 2 | идёт лицом (`walk_front`) | 4 |
| 3 | идёт спиной (`walk_back`) | 4 |
| 4 | сидит лицом (`sit_front`) | 1 |
| 5 | сидит спиной (`sit_back`) | 1 |
| 6 | держит предмет, лицом (`hold_front`) | 2 |
| 7 | держит предмет, спиной (`hold_back`) | 2 |

## Шрифты

Лежат в `src/assets/fonts/`, из интернета не загружаются. Все под свободной лицензией SIL OFL.

- **Press Start 2P** — заголовки и кнопки (пиксельный, с кириллицей).
- **Tiny5** — надписи в игре: облачка, таблички (маленький пиксельный, с кириллицей).
- **PT Sans** — длинные тексты.

## Как устроен код

- `src/iso.ts` — перевод координат экран ↔ сетка.
- `src/world/IsoRoom.ts` — комната: пол, стены, предметы на стенах, проходимость клеток, поиск пути.
- `src/world/Player.ts` — персонаж: ходьба по пути, повороты, анимации, падение.
- `src/world/Interactable.ts` — интерактивный предмет: подсветка контуром, искорки на телефоне.
- `src/scenes/RoomScene.ts` — общая основа комнат (ходьба, предметы, двери, падение сверху, облачка).
- `src/scenes/LobbyScene.ts`, `VhodScene.ts`, `SportScene.ts` — сами комнаты.
- `src/ui/` — окна поверх игры, правила, кнопки, экран загрузки.
- `src/texts.ts` — игровые фразы.
- `scripts/generate-sprites.mjs` и `scripts/sprites/` — генератор спрайтов.
